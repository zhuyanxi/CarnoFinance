# 中证1000期货贴水监控

该工具从 Eastmoney 公共行情接口读取中证1000指数和中金所合约行情，动态筛选当前存续的 `IM` 交割月合约。默认每 5 秒刷新一次，实时快照会覆盖写入 `options/data/latest.json`。

## 运行

从仓库根目录执行：

```sh
go run ./options
```

默认持续轮询。单次采集后退出：

```sh
go run ./options -once
```

调整轮询间隔（最小 1 秒）：

```sh
go run ./options -interval 2s
```

下载当前存续合约最近 365 个自然日的日线贴水记录：

```sh
go run ./options -history-days 365
```

历史数据写入 `options/data/daily_basis.csv`，按日期和合约列出指数收盘价、期货收盘价、贴水点数、每日贴水值、贴水率及年化贴水率。可用 `-output-dir` 更改输出目录。
交易时段执行时，接口返回的当日 K 线尚未收盘，文件中的当日贴水值会随行情变化；收盘后再次运行可更新为最终日线值。

## 指标定义

- 贴水点数 = 中证1000指数价格 - IM合约价格。正数表示期货贴水，负数表示期货升水。
- 每日贴水值 = 贴水点数 / 到期剩余自然日数；到期日当天不计算。
- 贴水率 = 贴水点数 / 中证1000指数价格 × 100%。
- 年化贴水率 = 贴水率 × 365 / 到期剩余自然日数。到期日当天不计算年化值。
- IM 合约到期日按交割月份第三个星期五推算；遇交易所节假日调整时，年化值可能与交易所日历口径略有差异。

`latest.json` 同时包含抓取时间和指数行情时间。公开行情接口的延迟及刷新频率由 Eastmoney 决定，轮询间隔不代表交易所级实时行情；请勿将其作为下单的唯一依据。
